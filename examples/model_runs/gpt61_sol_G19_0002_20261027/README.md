## 选中类的原始实验设计 / Selected-class experiments

### M1 · 1. 地质关系约束下的矿化—赋矿地层—侵入事件年代对比

**design**

利用已给定现场准入和矿山地质人员协作，先记录可见矿体与围岩的层理、接触、穿切和包裹关系，对实际能够取得的矿石及围岩标本编号并保存产状和位置。建议制作薄片和矿物成分、内部结构图像，筛选与原生矿化、后期脉体或侵入事件有明确关系的可定年矿物；其存在及分析平台均待确认。若围岩中确有碎屑锆石，建议开展U–Pb测年约束最大沉积年龄；该上限不直接等同沉积年龄。若发现可靠成矿或侵入定年载体，再选择适宜体系分别定年，并尽可能重复不同标本及矿物域，配置标准、空白及不一致年龄筛查。对区域海西期花岗岩，仅在能够新增取得有明确地质关系的样品并获得必要准入时建议取样定年，否则不假定已有可分析岩体样品。比较年龄及其不确定度，并与相对先后关系交叉核验。

**why_needed**

能够取得矿石与围岩，为从实际矿物载体和地质接触关系约束形成时序提供起点；仅凭区域广布某期花岗岩无法建立其与矿体的因果联系。

**expected_evidence**

获取可定年矿物的赋存位置、核心与边部结构、年龄及误差、不同事件间交切关系，以及在条件允许时取得的围岩沉积年龄边界、侵入年龄和成矿年龄。

**supports_hypothesis_if**

若矿化与沉积在独立沉积约束允许范围内同时，且被后期侵入切割，则支持沉积同生成分；若原生矿化与具有岩浆结构及接触关系的碳酸岩事件同步，则支持岩浆碳酸岩解释；若成矿矿物明显晚于已成岩围岩并伴交代前缘，则支持后生热液解释。若原生矿化早于花岗岩而热液边部与其同期，则支持早期矿体后遭叠加的复合序列。

**weakens_hypothesis_if**

可靠的矿化年龄显著晚于沉积会削弱纯沉积同生模型；可靠矿化早于相关侵入会削弱该侵入直接形成矿体的解释；若所谓热液年龄只对应晚期无矿边部，则不能用它证明整个矿体后生成因。模型间无法分辨的年龄区间不构成否定，而表示现有时序证据不足。

**limitations**

矿石和围岩是否含适宜、未重置的定年载体未知，实验需落实制样和年代学条件。碎屑锆石年龄通常只给沉积年龄上限，继承、普通铅、开放体系和变质重置均可误导。年龄相近不证明共同来源或成因，后期结晶年龄也不能自动代表主成矿年龄，必须保持矿物域与地质事件的对应。

### M2 · 1. 矿石—围岩接触及矿物世代的热液叠加检验

**design**

在实际可见且可安全进入的露头或采场，由矿山人员协助记录层状矿石、可能的脉体及接触位置；仅当这些关系实际存在时，对完整接触、切穿脉与两侧围岩配对取样，并选择相对少改造标本作比较，是否可取得须现场确认。建议以薄片、背散射成像及成分面扫描识别残余核心、交代边、裂隙充填和含矿矿物世代。不同位置重复观察，防止将单个标本的抛光截面误作普遍关系；将识别出的世代提交M1开展条件允许的分域定年，不额外假定某一热液阶段已存在。

**why_needed**

沉积或岩浆形成的早期矿体也可能被后期热液改造；辨认叠加关系是解释多组年龄并判断花岗岩相关事件所处位置的必要依据。

**expected_evidence**

获得脉体切穿早期矿石、早期矿物残余被晚期矿物替代、矿物生长边界、交代前缘与含矿阶段对应关系等观察，以及这些关系在不同标本间是否一致的记录。

**supports_hypothesis_if**

若早期含矿集合体被晚期脉体或交代边切割、替代且可分出独立世代，支持既有矿化受后期热液叠加的解释；若主要含矿矿物沿切穿已成岩围岩的交代前缘形成，支持后生热液成矿。若早期沉积或岩浆结构仍保存，则可据此检验其与后期改造的复合关系。

**weakens_hypothesis_if**

若重复标本显示所谓晚期交代边实际为同一阶段生长带，且无独立交切或替代证据，则削弱多阶段叠加解释；若后期脉体不含主要矿物且只局部切割既有矿石，则削弱其形成主体矿体的解释。未见叠加不能单独排除被完全抹去的热液事件。

**limitations**

标本可能偏向易采集部位，完全交代可抹去早期记录，变形与重结晶也可能产生类似纹理。相对先后不直接给出绝对年龄、流体来源或金属贡献比例；花岗岩与叠加事件的联系仍须独立年代及地质证据。

## 模型原始综合方案 / Overall plan

先以现场关系及矿石、围岩岩相识别事件和矿物世代，再落实适宜载体与分析条件进行分域定年，最后联合相对关系和年龄不确定度比较沉积同生、岩浆碳酸岩、后生热液及其复合序列。不能取得可靠定年载体时保留相对时序结论，不将缺测解释为任何模型成立。
